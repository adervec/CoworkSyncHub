Backup

Save a copy of everything these apps keep for you into one file, to store wherever you like: a USB stick, another cloud, an email to yourself. Your data never leaves this device unless you move the file.

What you have, and where

Each row is an app. This browser is what this device holds right now. Google Drive is the synced copy kept by apps you signed in to, which also carries your other devices. They are two separate copies: tick the ones the file should hold.

Reading…

Each browser, and on an iPhone each home-screen app, keeps its own data. For an app on your iPhone home screen, use Back up my data in that app's About panel.

The file is not encrypted and can hold personal data (training logs, recordings, notes): keep it somewhere private. Sign-in tokens are left out.

Open a backup file

Choose a file you saved earlier to see exactly what is in it, app by app, next to what this browser has now. Opening a file changes nothing. From there you can put back one app, several, or everything.

Restore puts back what you tick exactly as the file has it, and leaves everything else alone. Before it changes anything it downloads a safety copy of what it is about to replace. Only restore a file you made yourself.
